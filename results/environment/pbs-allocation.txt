PBS allocation records (sanitized)
==================================

The two-node parexp request waited for resources, received the same host in
both chunks, and was aborted by PBS after exceeding its 10-minute walltime.
Exit status: -29.

Two successful fallback jobs ran in the testes queue with one node and four
CPUs each: 1025654.ada and 1027387.ada. Both used the same compute node.

The testes Qlist does not expose other CPU nodes. Host-specific requests for
other nodes were rejected. This PR therefore contains one distinct node only.
